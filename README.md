# Django-приложение: Учебный сервис для запоминания слов

## 📚 Описание

Веб-сервис на Django, созданный для тренировки словарного запаса. Позволяет добавлять карточки со словами и переводами, просматривать их в виде таблицы и использовать тренажёр, проверяющий знания.

## 🛠 Технологии

- Django 4.x
- SQLite (встроенная БД)
- Bootstrap 5 (через CDN)

## 📸 Возможности

- Главная страница с навигацией
- Добавление карточек (форма)
- Просмотр карточек (таблица)
- Тренажёр для проверки перевода слов
- Валидация форм

## 📂 Страницы

| URL | Назначение |
|-----|------------|
| `/` | Главная страница |
| `/add/` | Добавление карточки |
| `/cards/` | Просмотр всех карточек |
| `/quiz/` | Тренажёр по словам |

## ▶️ Как запустить

1. Клонируй проект:

```bash
git clone https://github.com/ваш-пользователь/ваш-репозиторий.git
cd ваш-репозиторий
```

2. Установи зависимости:

```bash
pip install -r requirements.txt
```

3. Выполни миграции:

```bash
python manage.py migrate
```

4. Запусти сервер:

```bash
python manage.py runserver
```

5. Открой окно в браузере: http://localhost:8000
