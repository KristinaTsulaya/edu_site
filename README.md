# Django-приложение: Учебный сервис для запоминания слов

## Описание

Веб-сервис на Django, созданный для тренировки словарного запаса. Позволяет добавлять карточки со словами и переводами, просматривать их в виде таблицы и использовать тренажёр, проверяющий знания.

## Технологии

- Django + Django REST Framework (API).
- SQLite (встроенная БД)
- Bootstrap 5, кастомный CSS, JavaScript (AJAX, анимации)
- Хэширование (hashlib) для генерации "слова дня".

## Возможности

- Главная страница с навигацией
- Добавление карточек (форма)
- Просмотр карточек (таблица)
- Тренажёр для проверки перевода слов
- Поиск слов по базе карточек
- Быстрый старт обучения

## Страницы

| URL | Назначение |
|-----|------------|
| `/` | Главная страница |
| `/add/` | Добавление карточки |
| `/cards/` | Просмотр всех карточек |
| `/quiz/` | Тренажёр по словам |

## Как запустить

1. Клонируй проект:

```bash
git clone https://github.com/KristinaTsulaya/edu_site
cd edu_site
```

2. Установи зависимости:

```bash
python3.9 -m pip install -r requirements.txt
```

3. Запусти сервер:

```bash
python3.9 manage.py runserver
```

4. Открой окно в браузере: http://localhost:8000
